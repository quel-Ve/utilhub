## 1. 项目全貌：Utility Hub 是什么

**Utility Hub（5UtilityHub）** 是用户的 Windows 统一快捷键管家 — 一个常驻后台 + 托盘程序，把三个独立工具聚合为一：

| 原独立工具 | 功能 | 在 Hub 中的形态 |
|---|---|---|
| 19zorder-snapshot（C++ 版，已退役） | 窗口 z-order 快照/恢复 | 右 Alt + `,` `.` `/` 三槽位 |
| 6TaskbarSortTool（排序守护已退役） | 任务栏图标按规则排序 | 右 Alt + `;` |
| 21eq-switcher（独立 daemon 被取代） | HD 490 Pro 耳机 EQ 预设切换 | 右 Alt + `'` + 托盘菜单 + 面板 EQ 表 |
| 11cc-voice-input（复用） | Pause 键说话即语音输入 | Pause 开关录音 |

- **技术栈**：Python 3.12 + PyQt6（面板）+ pynput（全局热键）+ win32（托盘/窗口 API），子模块 sys.path 只读复用
- **运行形态**：`pythonw hub.py --daemon`，计划任务登录自启（最高权限，因需写 Equalizer APO config）
- **托盘**：原生 Win32 托盘（双击 = 快照槽 1；EQ 子菜单动态列出全部预设可手动切）
- **单实例**：Mutex `Local\UtilityHub` + PID 文件

## 2. 用户需求背景（为什么有这些功能）

用户是一名研究生（论文写作 + 编程 + 日常），典型的 Windows 重度多窗口用户，核心痛点与对应需求：

1. **窗口布局恢复**：写论文/编程时打开固定的窗口组合（编辑器、浏览器、PDF、终端…），频繁重建布局浪费时间 → 三槽位快照/恢复，一键还原整组窗口位置与 z-order
2. **任务栏整洁**：任务栏图标杂乱无章 → 按预设规则（正则匹配进程/应用）一键排序
3. **听歌 EQ 体验**：HD 490 Pro 监听耳机，不同流派需要不同 EQ 曲线 → 前台轮询网易云歌曲标题 → pyncm 推断流派 → 自动切换预设（游戏时 cs2 前台自动用 game 预设）；热键手动循环 电子→Indie→金属→日常
4. **语音输入**：打字慢 → Pause 键按住说话，faster-whisper 转录后自动粘贴
5. **统一入口**：讨厌多个常驻工具各自为政 → 全部聚合进一个托盘程序，一套热键体系

**用户的审美倾向（已有证据）**：
- Win10 原生风格（直角键帽、暗色 `#1F1F1F` 底、细分隔线）
- 粉色强调色 `#FF69B4`（用户指定；EQ 高亮另读系统主题色）
- 实时视觉反馈优先（面板、进度条、长按倒计时、刚做的排序 armed 效果）
- "要更美观"（本次会话诉求：参照 Win10 拖拽的灰色框 + 深灰弥散效果）

## 3. 热键体系（2026-08-14 触发规则定稿）

| 操作 | 行为 |
|---|---|
| 右 Alt 按下 | 仅开启会话，**不弹面板** |
| 右 Alt + `,` `.` `/` | 槽 1/2/3：短按 = 空槽快照 / 非空槽恢复；长按 ≥0.9s = 自动快照（进度条倒计时） |
| 右 Alt + `;` | 面板 + 排序块 armed 效果；**松开 `;` 才执行任务栏排序**（防抖 0.5s） |
| 右 Alt + `'` | EQ 预设循环（无防抖，按下即切换） |
| Ctrl 按住中 | 整个体系锁住（不弹面板、trigger 不生效 — 不干扰其他应用的 Ctrl+Alt 组合） |
| 面板出现后 | **只有右 Alt 松开才消失**；trigger 松开面板保留 |
| Esc（右 Alt 按住中） | 取消（含已 arm 的排序） |
| Pause | VoiceInput 语音输入开关 |

## 4. 预览面板的角色

面板是**所有热键操作的唯一视觉反馈面**：键位提示 + 槽位缩略图/布局示意 + 长按进度条 + EQ 预设表/当前高亮 + 排序 armed 效果。平时完全隐藏，只在整个热键会话中存在。

## 5. 面板规格（2026-08-14 现状）

### 5.1 窗口属性

| 属性 | 值 |
|---|---|
| 尺寸 | **1543 × 220 px**（固定，常量见 §6） |
| 位置 | 主屏可用区域**水平居中、贴顶**（y=0），仅主屏 |
| 窗口类型 | Qt Tool + FramelessWindowHint + WindowStaysOnTopHint（置顶） |
| 交互 | WindowDoesNotAcceptFocus + WindowTransparentForInput（**点击穿透、不抢焦点**） |
| 背景 | 半透明深灰 `rgba(31,31,31,242)` 满幅填充 |
| 边框/阴影（W2，P0 已实现） | 外圈 1px 亮边 `rgba(255,255,255,60)`（内描边，不扩窗口）+ 底部 1px 暗线 `rgba(0,0,0,160)`（面板厚度感） |
| 显隐动画（W3，P0 已实现） | 显示：**120ms 淡入 + 8px 下滑**（OutCubic）；隐藏：**80ms 淡出**后 hide；仅在显隐瞬间跑，绝不在 50ms set_hold 刷新中起动画 |
| 字体 | Microsoft YaHei UI（正文）、Consolas（EQ 数字摘要）、Segoe MDL2 Assets（空槽图标） |

### 5.3 ① 左侧键位提示块（0–100px，高 220px）

- **`;` 键帽**（K1，P0 已实现）：44×44 px Win10 直角键帽，**垂直居中 y=88**（列高 220 → 键帽 88..132，中心 110）；填充 `#2D2D2D`、1px 描边 `#5A5A5A`、白色 `;` 16pt 居中
- **键帽拟物**：顶 1px 亮线 `rgba(255,255,255,30)` + 底 2px 深边 `rgba(0,0,0,110)`（厚度感）；**按下态**（右 Alt 会话中）：填充压暗 `#262626` + 整体下移 1px + 底部深边减为 1px
- **"排序"标签**：10pt `rgba(190,190,190,195)`，y=140
- **armed 状态**（Alt+`;` 按住，2026-08-14 新增 + P0 修正）：整块灰色**直角**框 `#9E9E9E` α240 / 2px（内描边 0.5 偏移压准）+ 1px 内亮边 `rgba(255,255,255,50)` + 深灰弥散 `rgba(90,90,90,120)`；**`;` 键帽不跳位**（与常态共用同一绘制路径，位置像素级一致）；标签同位提亮为 `rgba(255,255,255,230)` 文案 **"松开执行排序"**

### 5.4 ② 竖分隔线

- 两条：x=106、x=967；1px 宽，y 14–192
- P0：**两端垂直渐隐**（α 0→46→0，中间段 `rgba(255,255,255,46)`）

### 5.5 ③ 槽位区（x 114–954，y=**33**（居中，P0 调整），三槽 272×153，间距 8）

- **缩略图**：快照截图（480px 缩至 272×153）+ 1px 内描边 `rgba(255,255,255,28)`（S1，与底色切开）
- **空槽**（S3，P0 已实现）：虚线框 `rgba(255,255,255,70)` 1px + **Segoe MDL2 相机图标** 20pt `rgba(255,255,255,90)` + "空槽" 13pt `rgba(255,255,255,110)` + 引导文案 "短按 , . / 保存布局" 9pt `rgba(255,255,255,70)`
- **布局示意覆盖层**（有快照时）：按屏幕比例的半透明蓝矩形 `rgba(60,130,220,70)` + 白 8pt 窗口标题
- **槽号键帽**：右下角 24×18px，深底 `rgba(20,20,20,190)` + 灰描边 + 白加粗 10pt
- **激活槽高亮**（按住的槽）：3px 粉框 `#FF69B4` + 下方进度条（y=THUMB_H+6+33，8px 高：白轨道 `rgba(255,255,255,90)` + 粉填充 `rgba(255,105,180,230)`，40ms→900ms 线性满格 = 长按快照倒计时）

### 5.6 ④ EQ 预设表（x 968–1543，575px）

- 无表头；5 行 × 40px，**整块垂直居中**（P0 调整）：`game / electronic(显示 elec) / indie / metal / daily`
- 行内容：预设名（x+18，64px）+ 参数摘要（x+84，Consolas 9pt 等宽对齐，如 `-5dB  50+2  220+1.5  1.6k+3  3.5k-2  10k+1`）
- **当前预设**（P0 强化）：整行粉高亮 `rgba(255,105,180,190)` + 左 3px 亮粉指示条 `rgba(255,140,200,255)` + **预设名加粗**（DemiBold）+ 白字 + **行尾 ● 指示点** `rgba(255,140,200,255)`；其余灰字 `#DCDCDC`
- 行间 1px 分隔线**水平渐隐**（α 0→26→0，P0 调整）
- 高亮色动态读注册表 `DWM\AccentColor`（AABBGGRR 字节序，失败回退 `#FF69B4`）

### 5.7 ⑤ 底部消息行（可选）

- 提示文本（如 "Snapshot done"）：12pt 白 α230，y=190 全宽居中

## 6. 实现约束（改尺寸必须知道）

- 所有尺寸是 `preview.py` 顶部常量：`SIDE_HINT_W=100`、`THUMB_W/H=272/153`、`THUMB_GAP=8`、`EQ_TABLE_W=575`、`W/H=1543/220`、`TOP_MARGIN=(H-THUMB_H)//2=33`、`PROGRESS_H=8`；P0 美化常量集中在文件顶部"Win10 美化方案 P0"注释块（BORDER_CLR/SHADOW、KEY_TOP_HILITE/BOTTOM_EDGE、ARMED_INNER、DIVIDER_ALPHA、THUMB_BORDER、EMPTY_DASH/ICON/TITLE/HINT），新增视觉常量请继续集中于此
- 窗口可无边框、置顶、点击穿透，但**必须保持 220px 高以内**（不能挡到屏幕顶部内容太多）且不可抢焦点
- 性能：面板在按键会话中每 50ms 收到 `set_hold` 刷新（进度条），绘制须轻量（无复杂渐变动画循环）；显隐动画只在 show/hide 瞬间跑

## 7. 当前已知视觉薄弱点（供改进参考）

P0（2026-08-14 已实现）：✅ 外圈亮边+底部暗线 ✅ 空槽虚线框+相机图标+引导文案 ✅ armed 直角框+内亮边+键帽不跳位 ✅ 键帽拟物高光/按压缩动 ✅ 显隐淡入淡出动效 ✅ 分隔线/行分隔线渐隐 ✅ EQ 当前行加粗+● 指示点 ✅ 槽位/EQ 表垂直居中

P1 候选（未实现）：
1. **尺寸/位置硬编码** — 仅主屏水平居中贴顶，不支持多屏、DPI 缩放细节
2. **EQ 表缺表头** — 5 行信息密度高，无列标题视觉锚点（P0 加粗/● 已缓解）
3. **无真实投影/圆角** — 目前只有 1px 亮边+暗线，W2 可升级为渐变阴影或圆角容器
4. **进度条样式** — 目前是纯矩形条，可加两端圆角/发光
5. **armed 效果动画** — 弥散可加 50-80ms 渐显，避免瞬变
